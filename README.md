


Main classes:
- `Persoana` – base class containing personal information
- `Angajat` – derived class representing employees
- `Programator` – derived class representing programmers
- `Departament` – manages a collection of employees

Features :
- Employee and department management
- Validation using exceptions
- Salary calculation
- Input/output operator overloading
- Inheritance relationships between classes
- Dynamic management of character arrays and employee collections
